# Architecture Overview: Data Processing & Visualization

This document provides a high-level architectural overview of the CS2 Data Visualization Project, detailing how raw `.dem` replay files are transformed into interactive analytical dashboards. 

The project is broadly divided into two main layers:
1. **Data Processing (`src/data_processing`)**: The ETL (Extract, Transform, Load) pipeline that parses raw game data into structured CSVs.
2. **Visualization (`src/visualization`)**: The rendering layer that consumes the processed CSVs to generate interactive Plotly charts.

---

## 1. Data Processing Pipeline

The data processing layer uses the `awpy` library to parse CS2 `.dem` files. It extracts complex in-game events (ticks, rounds, kills, economy) and structures them into aggregated `.csv` files stored in `analysis_results/`.

For detailed documentation on specific parsers, please refer to the individual files in the [`src/data_processing/docs/`](../src/data_processing/docs/) directory:

- **[parse_demos.md](../src/data_processing/docs/parse_demos.md)**: Extracts per-player, per-side combat and utility statistics (kills, assists, headshots, grenades). Outputs `budapest_major_stats.csv`.
- **[parse_economy.md](../src/data_processing/docs/parse_economy.md)**: Parses the starting cash balance for every player at the beginning of each round. Outputs `budapest_major_economy.csv`.
- **[parse_match_details.md](../src/data_processing/docs/parse_match_details.md)**: Extracts per-team, per-side round win/loss totals. Tracks halftime side-swaps and outputs `budapest_major_match_details.csv`.
- **[parse_outcomes.md](../src/data_processing/docs/parse_outcomes.md)**: Determines whether a player's team won each individual round. Outputs `budapest_major_outcomes.csv`.
- **[parse_team_outcomes.md](../src/data_processing/docs/parse_team_outcomes.md)**: Determines round-by-round win outcomes aggregated at the team level (incorporating complex overtime logic). Outputs `budapest_major_team_outcomes.csv`.
- **[parse_positions.md](../src/data_processing/docs/parse_positions.md)**: Extracts and downsamples player coordinates, classifying them by map level (upper/lower) and binning them into a grid for heatmaps. Outputs `budapest_major_positions.csv`.
- **[parse_weapon_kills.md](../src/data_processing/docs/parse_weapon_kills.md)**: Aggregates kill counts mapped to specific normalized weapons. Outputs `budapest_major_weapon_kills.csv`.

## 2. Visualization Layer

The visualization layer consumes the structured `.csv` files generated by the processing pipeline. It utilizes `plotly` to render rich, interactive charts that power the user dashboard.

For detailed documentation on specific visualization components, please refer to the individual files in the [`src/visualization/docs/`](../src/visualization/docs/) directory:

- **[diverging_bar.md](../src/visualization/docs/diverging_bar.md)**: Consumes `budapest_major_stats.csv` to create a diverging bar chart comparing CT vs. T side performance for players, teams, or entire maps.
- **[economy_viz.md](../src/visualization/docs/economy_viz.md)**: Consumes `budapest_major_economy.csv` to generate a multi-series line chart depicting team economy progression across rounds, complete with phase separators (halftimes, overtimes).
- **[headshot_scatter.md](../src/visualization/docs/headshot_scatter.md)**: Consumes `budapest_major_stats.csv` to produce a bubble scatter plot with trendlines, comparing Headshot % against Kills Per Round (KPR) or Total Kills.
- **[position_heatmap.md](../src/visualization/docs/position_heatmap.md)**: Consumes `budapest_major_positions.csv` to overlay player position density heatmaps onto actual CS2 map radar images, supporting upper and lower map levels.
- **[spider_player_performance.md](../src/visualization/docs/spider_player_performance.md)**: Consumes `budapest_major_stats.csv` to render radar (spider) charts, allowing multi-metric visual comparisons of up to two players simultaneously.

## Data Flow Summary

The overall flow of the application can be summarized as:

1. **Raw Demos** (`dem_files/`) + **Tournament Bracket** (`src/budapest_major.json`)
2. ➡️ **Data Processing** (`src/data_processing/*.py`)
3. ➡️ **Structured Data** (`analysis_results/*.csv`)
4. ➡️ **Visualization** (`src/visualization/*.py`)
5. ➡️ **Interactive Dashboard** (Streamlit Application)
